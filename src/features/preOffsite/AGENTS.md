# Pré-Offsite

- Pré-Offsite form structure lives in offsite_config (PADRAO is only fallback). Admin edits use offsite_config_rascunhos + offsite_config_publicar: add/reorder/archive ids, never delete, with audited answer migration; protects answers keyed by names.
- Pré-Offsite uses isolated offsite_* tables, verified chair participants and protected admins; admin status never authorizes a personal response. Versioned RPCs/config preserve privacy and old answers through new namespaces and retired IDs in history. Shared visibility projections drive empty read-only admin previews, never impersonation; consolidation/Excel stay admin-only with no legacy permission or KPI writes.
- Config may carry display-only overrides (question `rotulo`, Bloco 0 `kpisTexto`, form-local `bsc2027` list); blocks with no active question are hidden and renumbered by index helpers, keeping internal ids/answer keys and the app's BSC tables untouched.
- Content-only database updates use a versioned SQL transformation recorded by migration and a separate data operation; this respects DDL-only migrations and preserves response rows.
- 4C uses produto4CVisivel for admin, annex and Excel projections so retired answer fields remain stored without being displayed; completion checks Position and, for a used Other item, Name only.
- Form progress uses completudeDetalhada per step (only required questions/fields visible to the director via perguntaPara; CAMPOS_NAO_CONTAM fields never count in any block and 4B rows are optional; archived items removed by prepararConfig); the form, admin preview and review share it, keeping completion and answers unchanged.
- Admin read-only director view reuses the form Editor with an `alvo` (answers already readable by offsite_admin via RLS); persist is disabled so viewing never writes, keeping status and timestamps intact.
- Admin status labels use situacaoResposta with the displayed completion percentage across table, reader and Excel; submitted takes precedence, and computed completion never changes persisted status or editability.
